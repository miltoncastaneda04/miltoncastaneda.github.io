Sitio personal de Milton Castañeda — Ingeniero de Ciberseguridad y Redes.

🌐 Vive en: [miltoncastaneda.com](https://miltoncastaneda.com)

## Estructura

```
/
├── index.html              # Landing principal (selección de camino)
├── portafolio/             # Trayectoria profesional / CV online
│   └── index.html
├── servicios/              # Página de servicios para PyMEs
│   └── index.html
├── assets/
│   ├── styles.css          # Estilos compartidos
│   └── script.js           # i18n + interacciones
├── CNAME                   # Dominio personalizado
└── .nojekyll               # Desactiva procesamiento Jekyll
```

## Stack

- HTML5 + CSS3 + JavaScript vanilla
- Sin frameworks, sin build process
- Tipografía: Space Grotesk + Inter + JetBrains Mono (Google Fonts)
- Hosting: GitHub Pages
- Dominio: Cloudflare Registrar
- Bilingüe (ES/EN) con switcher persistente vía localStorage
